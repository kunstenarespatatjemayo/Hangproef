# Hangproef

Pagina waarop bezoekers de schilderijen bekijken, ze met hun camera in hun eigen
woning of bedrijfspand passen, en contact opnemen.

Alleen index.html hoort in deze repository; atelier.html blijft op de computer
van de kunstenares.

De grote afbeelding achter de naam en de portretfoto zijn voorbeeldillustraties;
vervang ze in het atelierbeheer door eigen fotos.

## Rechtstreekse links

- #galerij opent alle werken
- #tool opent de proefopstelling
- #over opent "wie is de kunstenares"
- #kantoor opent het kantoorabonnement
- #contact opent het contactformulier
