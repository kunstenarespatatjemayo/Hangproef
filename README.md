# Hangproef

Pagina waarop bezoekers de schilderijen bekijken, ze met hun camera in hun eigen
woning of bedrijfspand passen, en contact opnemen.

Alleen `index.html` hoort in deze repository. Het beheerbestand `atelier.html`
blijft op de computer van de kunstenares.

Werken toevoegen gaat via de gekoppelde Google Drive-map (zie INSTALLATIE.md);
aanvragen en bezoekcijfers komen in het gekoppelde spreadsheet.

## Rechtstreekse links

- `#galerij` opent de galerij
- `#tool` opent de proefopstelling
- `#over` opent "wie is de kunstenares"
- `#kantoor` opent het kantoorabonnement
- `#contact` opent het contactformulier
