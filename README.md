# Hangproef

Een pagina waarop bezoekers de schilderijen bekijken, ze met hun eigen camera
aan hun muur passen en contact kunnen opnemen.

## Online zetten

1. Upload `index.html` naar deze repository (Add file → Upload files).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, map `/ (root)`.
3. Na een paar minuten staat de pagina op
   `https://<gebruikersnaam>.github.io/<repository>/`

Live meekijken met de camera werkt alleen op zo'n https-adres, niet op een
bestand dat je van je bureaublad opent.

## Bijwerken

De werken en de teksten worden beheerd in `atelier.html` — dat bestand hoort
NIET in deze repository, dat bewaar je op je eigen computer.

In `atelier.html`:

1. Werken toevoegen of teksten aanpassen.
2. Klikken op "Bezoekerspagina opslaan (index.html)".
3. Het nieuwe `index.html` hier opnieuw uploaden (Add file → Upload files).
   GitHub vervangt het bestaande bestand; het webadres blijft hetzelfde.
